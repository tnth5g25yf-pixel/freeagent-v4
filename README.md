# FreeAgent v4 (Expo)

This repository contains a minimal Expo React Native starter app so you can run the app on your iPhone using Expo Go.

Quick start

1. Install Node (>=16) and npm or yarn.
2. In a terminal at the repo root run:

   npm install

3. Start Expo:

   npx expo start

4. Install Expo Go on your iPhone from the App Store and scan the QR code shown by `expo start`.

Notes

- To build a standalone .ipa for TestFlight/App Store you can use EAS Build (requires an Apple Developer account). Run `npm run eas:build` after configuring EAS and adding credentials.
- If you want a fully native Xcode project instead, I can eject the project or create a SwiftUI app.
